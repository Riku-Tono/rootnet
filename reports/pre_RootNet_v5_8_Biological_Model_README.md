# RootNet v5.8.0 Biological Model

菌類・藻類・共生体に着想を得た人工生態系モデルです。v5.7.2の乱数分離、保存・再開、系統、防疫、分断・再接続を保ち、日々の中心計算を擬人的な性格判断から生理資源の収支へ変更しました。

これは実在する特定のフサリウム種を校正した予測モデルではありません。現在の位置づけは「生物学的に着想された検証可能な人工生態系」です。

## 生物モデル

初期個体は三つの機能群へ割り当てられます。

- `fungus`: 基質由来の炭素を利用し、光合成しない
- `alga`: 光から炭素を獲得する
- `symbiotic`: 光合成と基質利用を組み合わせる

各個体は炭素、水、窒素の内部プールを持ちます。毎日、環境からの入力、RootNet内の移送、維持代謝、成長消費を順に計算します。欠乏が続くと組織損傷が蓄積し、回復しなければ欠乏死に至ります。

RootNetの資源移送は、伝導率、供給側の共有形質、両個体の融合適合性、資源濃度差で決まります。移送量は供給側から減らし、受給側へ同量を加えるため保存的です。

詳細な変数と式は `BIOLOGICAL_MODEL_SPEC.md` を参照してください。

## 擬人的変数の扱い

schema v11以前の保存データを読めるよう、`Temperament`、`LifeNeeds`、`RelationshipState`は互換データとして残しています。ただしv5.8.0の通常の日次計算では、性格による行動選択、援助要求、信頼更新を実行しません。系統樹画面にもこれらを表示しません。

## 乱数と保存

- `world`: 日照、天候、潮汐、基盤環境
- `individual`: 遺伝子、生理形質、潜在能力
- `mutation`: 遺伝変異、損傷、毒性変異
- `action`: 発芽、移動、相互作用などの離散事象

保存形式はschema v12です。生理形質、全資源プール、欠乏日数、累積入出量、日別物質収支を保存します。schema v11は読み込み時に、生物形質と資源状態を決定的に補います。

## 実行

~~~powershell
python main.py --days 10 --seed 42
~~~

既定の保存先は `fusa_rootnet_v5_8_0.json`、系統樹は `fusa_lineage_tree.html` です。

## 検査

~~~powershell
python -m unittest discover -v
python validate_v5_8_0.py
~~~

新規検査は機能群、非擬人化、菌類と藻類の炭素獲得差、保存的資源移送、欠乏死、120日物質収支、schema v11移行、保存・再開一致を対象にします。
